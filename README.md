# 基于全网大数据的文创热点分析与智能选品系统 V1.0

陕西理工大学 软件著作权登记源代码包。

## 运行环境

- Node.js 22 及以上（仅使用 Node.js 内置模块，无需安装第三方依赖）
- 浏览器：Chrome 或 Edge 最新版本

## 启动

```
node server.js
```

服务默认监听 `http://127.0.0.1:4103`，可通过环境变量 `PORT` 修改端口。

## 初始账号

首次启动自动生成于 `data/` 目录，属于本地演示账号，不属于生产凭据：

| 账号 | 角色 |
|---|---|
| admin01 | 系统管理员 |
| analyst01 | 数据分析师 |
| designer01 | 产品设计师 |
| operator01 | 运营专员 |

## 目录说明

- `server.js`：HTTP 服务、路由与鉴权入口
- `lib/`：存储、导入、分析、选品、报告等服务模块
- `public/`：前端页面、样式与视图脚本
- `data/`：运行数据目录，首次启动自动创建，不随源码包分发；建议定期通过系统内备份功能导出
